# Mini Project: Food Ordering App with Pocketbase
**By Kamon Charoensri - 65114540011**

**Feature**
- CRUD
- Faker script
- using builder pattern in project

**Setup Pocketbase and run faker script**
1. ```
   pocketbase serve
   ```
2. ```
   node seed.mjs
   ```

**How to Run**
1. ```
   git clone https://github.com/Jxuu03/65114540011-MobileApp.git
   ```
2. ```
   git switch miniproject
   ```
3. ```
   git pull
   ```
4. ```
   cd finalproj
   ```
5. ```
   flutter pub get
   ```
6. ```
   flutter run -d chrome
   ```
